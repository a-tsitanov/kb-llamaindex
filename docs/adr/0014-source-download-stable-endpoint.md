# ADR-0014: Скачивание исходных документов через стабильный API-endpoint (не presigned URL)

- Статус: Принято
- Дата: 2026-06-07

## Контекст

Ответы поиска выставляют `doc_id` в `sources[]`/`documents[]`, и непрерывный
wiki-редактор (ADR-0012) должен связывать каждую статью обратно с исходными
файлами-источниками (секция `== Источники ==`). Оригинальные файлы лежат в MinIO
(URI хранится в Postgres `documents.path`). Presigned URL object-store были бы
естественным механизмом скачивания, но они истекают, раскрывают backend хранилища,
обходят авторизацию приложения и менялись бы каждый раз при регенерации —
нестабильны для встраивания в долгоживущие wiki-страницы.

## Решение

Обслуживаем скачивания через **стабильный, защищённый авторизацией
API-endpoint** `GET /api/v1/documents/{doc_id}`. Он ищет `documents.path` в
Postgres и стримит файл из MinIO (`stat_object` + `stream_object`), с
санитизированным по RFC 6266 `Content-Disposition`, 404 для отсутствующих
документов/объектов и 503, когда хранилище недостижимо; legacy-документы с
локальным путём стримятся с диска. Wiki-редактор строит ссылки `== Источники ==`
**детерминированно** (не генерируются LLM) как
`{docs_base_url}/documents/{doc_id}`, указывающие на этот endpoint.

## Последствия

- Один стабильный, постоянный, проверяемый авторизацией URL на документ,
  безопасный для встраивания в wiki-страницы и результаты поиска; backend
  хранилища остаётся скрытым за API.
- API стримит каждое скачивание (без отгрузки на CDN object-store / presigned
  прямую загрузку); принято для контролируемой внутренней KB.
- Ссылки на источники детерминированны и вне прозы, которой владеет бот-LLM,
  поэтому они не могут быть галлюцинированы или дрейфовать.

## Рассмотренные альтернативы

- **Presigned URL MinIO** — истекают, раскрывают backend, обходят авторизацию
  приложения и меняются при регенерации → нестабильны для встраивания в wiki.
- **Ссылки на источники, сгенерированные LLM** — риск
  галлюцинированных/некорректных URL; ссылки строятся детерминированно взамен.

## Дополнение (2026-10-14): оригинал рядом с текстом

Клиенты, конвертирующие файлы до загрузки (web UI офлайн-кластера, loadtest
loader через docs2md), отправляют в `POST /api/v1/ingest` текст (`file`, `.md`) и
опционально исходный бинарь (`original`, например `.docx`/`.pdf`). Оригинал
кладётся в MinIO как `<doc_id>/original/<санитизированное имя>`, его URI — в
nullable-колонку `documents.original_path` (добавляется идемпотентно
`scripts/setup_db.py`). Пайплайн его не читает.

`GET /api/v1/documents/{doc_id}?variant=original|text`: без параметра отдаётся
оригинал, если он сохранён, иначе текст (`documents.path`) — поэтому ссылки wiki
и поиска не меняются и ведут на оригинал там, где он есть; `variant=text` всегда
отдаёт текст; `variant=original` без сохранённого оригинала → 404.
`Content-Type` определяется по расширению имени (fallback — тип, сохранённый в
MinIO), `Content-Disposition` — прежний санитизированный `attachment`. Старые
документы оригинала не имеют.

## Дополнение (2026-10-20): журнал выдач и границы легаси-ветки

Маршрут отдаёт исходный бинарник целиком — всё, что не попало в граф.
Поэтому у него два свойства, которых нет у поиска.

**Каждая выдача пишется в журнал** `document_download` (таблица в схеме
графа): `doc_id`, эффективный вариант, выданный путь, `principal` (`owner`
ключа — тот же словарь имён, что у `documents.source_kind`), `tenant_id`,
время. Запись обязательна: не удалось записать — не отдаём, 503. Внешнего
ключа на `documents` у журнала НЕТ намеренно — он обязан пережить удаление
документа и графа, иначе каскад стёр бы ровно те строки, ради которых его
ведут. Промахи (404) не пишутся: журнал — материал расследования, а не лог
обращений. Чтение журнала в HTTP не выставлено — `IntakeRepository.
downloads_of` для операторского скрипта и psql.

**Легаси-ветка чтения с диска ограничена.** В `documents.path` у части
дорелизных строк лежит локальный путь, и маршрут читает его с диска.
Источник пути серверный, дыры нет, но «прочитать произвольный путь из
колонки БД» — слишком широкое полномочие под арендаторами. Границы: только
граф `default` (локальные пути есть лишь в строках до мультиграфа) и белый
список `API_UPLOAD_DIR` с разрешением пути (`resolve`) до сравнения, так что
ни `..`, ни символическая ссылка из каталога не выводят.
